# 麻将桌面 · 发布仓库

这个仓库只放两样东西：

- `version.json` —— 软件检查更新时读的清单
- **Releases** 里的安装包和热补丁

**源码不在这里。** 麻将桌面是作者自己写的 Windows 桌面壳（壁纸、图标、小组件、桌宠全部自己画），以安装包形式分发。

## 安装

下载 `麻将桌面-安装版-x.y.z.exe`，双击安装即可。默认装在你自己账户目录下
（`%LOCALAPPDATA%\Programs\麻将桌面`），**不需要管理员权限**，也不改系统其它地方。

卸载：Windows 设置 → 应用 → 麻将桌面 → 卸载。配置不会被删，开机自启项会一并清掉。

首次运行如果 Windows SmartScreen 或杀软拦一下，是因为安装包没有代码签名证书，
不代表有问题 —— 装完运行同一个文件就不再弹。

## 自动更新

软件里预置了本仓库 `version.json` 的地址，你什么都不用配置：

- 启动后每隔一天自动查一次，发现新版只在「设置中心 → 更新与备份」里提示一句，**不会自作主张下载**
- 界面类的小更新走热补丁，几百 KB，装完自动重启一次生效
- 改到底层逻辑的会提示你重新下载安装包
- 不想联网查更新：把「更新源」那一栏清空即可

## 安全边界

- 补丁一律要过 SHA256 校验；清单里没写 sha256 的直接拒装
- 热补丁只能带界面资源（html / 图片 / 视频 / 字体等），`main.js`、`preload.js`、
  `package.json` 在黑名单里，改这些必须整包重发
- 软件对外联网只有两处：检查更新（本仓库）、音乐条封面查询（music.163.com，
  会把正在播放的歌名和歌手作为搜索词发出去 —— 不想要就在设置里关掉）
- 桌宠的「键盘联动」只统计敲击次数，不记录、不保存、不上报按的是哪个键

## 反馈

软件内「设置中心 → 问题反馈」可以导出诊断信息，发给作者。
